## Linked list
- Linear , Dynamic
- end node references null
- has a relation
- you only know the root node (the starting node)
- can mimic all other data sturctures
- when root set to null entire linked list is destroyed(with AGC (auto garbage collection))
- if last node is not made null we will refer to garbage

### Types:
#### Linear linked list:
- []-->[]-->[]-->null

#### circular linked list:
- root and last
- one way

#### doubly linked list:
- []<->[]<->[]

#### Circular doubly linked list:
- root and last and also in reverse
