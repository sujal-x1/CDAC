- **Js is synchronous single threaded lang
- as soon as the prog is run the global execution context is created (memory , code)
- Memory=variable environment(keyvalue,func) //UNDEFINED at start
- code=Thread of Execution (gives the values to vars)
- JS loads all functions and variables as it starts
- Then values are assigned / functions are invoked

## Hoisting in JavaScript

**Hoisting** means JavaScript processes **declarations before executing the code**, so some variables/functions can be used before their declaration appears.
