/*

What should happen in the following code logically?

Thread t1 waits until flag becomes true.

Thread t2 sets flag = true after 1 second.

But sometimes:
Thread t1 may never exit the loop.

Why?

Because:
• Thread t1 reads flag from main memory once
• Copies it into its working memory
• Keeps checking its local copy
• It never re-reads main memory

Even though thread t2 updated the flag in main memory,
thread t1 does not see it.

This is called a "visibility problem".

*/

package core1;

public class DemoWithoutVolatile {

     static boolean flag = false;

    public static void main(String[] args) {

        Thread t1 = new Thread(new Runnable() {
            @Override
            public void run() {
                while (!flag) {
                    // waiting
                }
                System.out.println("Flag changed!");
            }
        });

        Thread t2 = new Thread(new Runnable() {
            @Override
            public void run() {
                try {
                    Thread.sleep(1000);
                } catch (Exception e) {
                    e.printStackTrace();
                }
                flag = true;
                System.out.println("Flag set to true");
            }
        });

        t1.start();
        t2.start();
    }
}
